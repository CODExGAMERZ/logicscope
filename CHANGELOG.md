# Changelog

All notable changes to the "LogicScope" extension will be documented in this file.

## [1.0.0] - 2026-06-15

### Added
- Initial release of LogicScope.
- Support for real-time control flowcharts for Python and JavaScript using local Tree-sitter WASM parsers.
- UML Class Diagram extraction for object-oriented structures.
- Recursion Tree visualizer highlighting parameters, return values, and call stacks.
- Sidebar UI panel for configuration adjustments (update modes, learning styles, manual override dropdowns).
- Optional Bring-Your-Own-Key (BYOK) AI explanation layer with support for Groq and Gemini.
- Secure credential management using VS Code's native SecretStorage API.
- Fully offline rendering using bundled Mermaid.js.
